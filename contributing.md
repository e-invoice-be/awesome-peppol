# Contribution guidelines

Thank you for helping to improve this list.

## Scope

Entries must be useful to people who build on, connect to or learn about the Peppol network. Examples:

- Peppol specifications (BIS, PINT, eDelivery) and national specifications used over Peppol.
- Access Point, AS4 and SMP software.
- Validators, Schematron rules and test files.
- Libraries, command-line tools, MCP servers and agent skills that work with Peppol documents or the Peppol network.
- Participant directories and lookup tools.
- Learning resources from authorities, OpenPeppol and the community.

General e-invoicing resources that do not relate to Peppol fit better in [awesome-einvoicing](https://github.com/facturxapi/awesome-einvoicing).

## Neutrality

This list is vendor-neutral. The maintainers of this repository run a Peppol Access Point, and their own projects follow the same rules as all other entries.

- Commercial and open-source projects are accepted on equal terms.
- Descriptions are factual. No marketing language, superlatives, prices or claims that are not on the linked page.
- One entry per project. Do not add the same project to more than one section.

## Quality

- The link must work (HTTP 200 or a valid redirect).
- Software projects must show activity in the last 3 years. Older projects are accepted only when they are a reference implementation that is still in use. Say so in the description.
- Archived or empty repositories are not accepted.

## Format

- One line per entry: `- [Name](https://example.com) - Description.`
- The description starts with a capital letter, ends with a period and has about 10 to 20 words.
- Keep entries in alphabetical order within each section (ignore case).
- Do not use em dashes.

## How to submit

1. Fork this repository.
2. Add your entry to the correct section of `README.md`.
3. Open a pull request with one entry per pull request, and say how the entry relates to Peppol.

All pull requests run [awesome-lint](https://github.com/sindresorhus/awesome-lint) and a link check.
